# AntuDevops POS — Releases

Official installers and updates for **AntuDevops POS**.

The desktop app checks this repository for new versions and offers them in-app (with release notes),
so stores don't need to download anything manually. Download from
[Releases](https://github.com/Antu-Devops/pos-public/releases) only when installing a new computer.

## Installing

1. Download `AntuDevops-POS-Setup-<version>.exe` from the latest release.
2. Install on the store's **server PC first**, then on every other terminal.
3. Updates afterwards arrive automatically inside the app.

> Always update the server PC before the other terminals: terminals won't run against a database
> from a newer version.
